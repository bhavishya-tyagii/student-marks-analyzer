## 🌌 About the Project

Student Marks Analyzer is a Python project designed to analyze student marks and summarize academic performance.

## ✨ Planned Features

- Calculate total marks and average.
- Identify the highest and lowest marks.
- Calculate percentage.
- Assign grades based on marks.
- Display a simple performance summary.

## 🛠️ Tech Stack

- Python
- Basic calculations and conditional statements

## 🎯 Learning Goals

- Practice Python fundamentals.
- Learn basic data analysis.
- Build a foundation for future Data Science projects.

## 🚧 Project Status

Currently in development. Features will be added as the project grows.
